# Removing duplicates
The dataset in the layoffs table had no unique identifier so I made use of window functions. I selected all the columns in the table and I also "partitioned by" all the columns in the table then I eventually added a row_number(). This was I was able to spot duplicate records in the table by spotting the records that had a row number greater than 1. I did this using the concept of subqueries in sql. 
 
-after finding the duplicates rows in the dataset, I had no option than do delete those records but MySQL does not support deleting records that were found via a subquery or cte. so I created a new table called "layoffs_staging" and I imported the the updated layoffs table into it; the layoffs table containing the row number.  after importing the updated data into a new table, I was able to delete all the duplicate records in the table. 

- after deleting the duplicate records, I deleted the first layoffs_staging table that i created and then I renamed the "layoffs_staging2" table to layoffs_staging. I ran the sql query to check for duplicates again and I confirmed that there were no longer duplicate records in the dataset.
