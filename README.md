# 🗄️ SQL Data Analysis Projects

## 📌 Overview

This repository contains a collection of **data analysis projects completed using SQL**.

The projects demonstrate practical applications of SQL for **data querying, data manipulation, data exploration, and analysis**, using structured datasets to answer analytical questions and generate meaningful insights.

Each project is organized in its own folder and includes a detailed **README file** documenting the dataset, analytical approach, SQL techniques used, queries performed, and key insights.
